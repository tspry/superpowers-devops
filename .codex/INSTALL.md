# superpowers-devops for Codex

To install superpowers-devops in Codex, add the following to your system prompt or agent instructions:

---

You have superpowers-devops installed. The skills are located at the root of this repository under `skills/`.

At the start of every session, read and follow `skills/using-superpowers-devops/SKILL.md`.

The skill will orient you to the full DevOps skill set and tell you when to invoke each one automatically.

When a skill is referenced, read the corresponding `skills/<skill-name>/SKILL.md` file and follow its instructions.
